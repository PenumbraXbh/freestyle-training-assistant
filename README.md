# Freestyle 训练助手

面向 freestyle 舞者的个人训练日志与灵感助手。本项目探索如何用低阻力记录沉淀训练经验，并让历史记录在回顾和下一次练习中重新产生价值。

> 当前为可交互产品验证 Demo。AI 生成、语音转写、账号登录与云同步均为模拟能力；演示数据只保存在当前浏览器，不代表产品已正式上线。

## 在线体验

[打开产品 Demo](https://penumbraxbh.github.io/freestyle-training-assistant/)

建议从“体验完整演示”进入。页面会自动载入脱敏示例记录，可以直接体验今天、历史、足迹和训练灵感等主要流程。可在“账户与数据”中清空或重新载入演示数据。

## 项目背景

Freestyle 训练往往持续时间长、内容开放且高度个性化。舞者可能围绕少量问题反复尝试，却很少愿意填写标准化训练表单；散落在备忘录中的感受，也难以在未来训练中再次被利用。

项目因此将产品定位从早期的“AI 分析舞蹈动作”收缩为“训练日志 + 灵感助手”，形成以下闭环：

```text
按需获取灵感 → 离开产品进行真实训练 → 低阻力记录
→ 历史回顾与训练足迹 → 再次获得练习刺激
```

训练灵感可以完全跳过，产品不监控训练过程，也不评价用户水平。

## Demo 已实现

- 今天、历史、足迹三项主导航及独立记录、灵感页面
- 主要舞种单选、补充标签多选、自定义标签和保存校验
- 训练记录创建、编辑、永久删除与历史关键词、日期、舞种、标签筛选
- 随机、模糊方向和足迹上下文三类模拟灵感，支持采用后自动带入记录
- 5 条有效记录、20 个有效信号的足迹门槛及分舞种研究线索
- 语音转写确认流程、用户反馈、互斥 A/B 实验分桶与本地事件记录
- 响应式桌面与移动端布局、本地数据导出和演示数据重置

## AI 方案

AI 设计重点不是扩大模型能力，而是约束其只能基于用户记录生成可追溯内容。方案将统计判断交给确定性规则，通过生成门槛、候选 ID、证据 ID、结构化 Schema、出站校验、有限重试和安全降级降低编造与越权判断风险。

完整工作区已形成 Prompt、生成工作流、3 套 Schema、24 条回归用例，以及包含 168 个词条并覆盖 11 个舞种语境的领域词表。公开摘要见 [AI 方案说明](docs/ai-spec/README.md)。这些资产目前属于设计与离线验证成果，不代表已完成线上模型效果验证。
